# وثيقة متطلبات المنتج (PRD) — «دفتر الدرجات الذكي»

**اسم التطبيق:** دفتر الدرجات الذكي (MyApp)
**الحزمة:** `com.alborihi.myapp`
**النوع:** تطبيق أصلي (Native Android) | مستقل بالكامل (Offline-first)
**الواجهة:** Jetpack Compose + Material Design 3
**اللغة البرمجية:** Kotlin | **اللغات:** العربية (افتراضي) والإنجليزية (دعم RTL إلزامي)
**المتطلبات:** minSdk 24 | targetSdk 34 | الوضع الداكن: مدعوم
**الوضع:** تطبيق حقيقي متكامل (Production-grade)، لا نموذج تجريبي.

## 5. تدفقات المستخدم (User Flows)

### 5.1 تدفق إضافة طالب
```
[لوحة التحكم] → [إدارة الطلاب] → [زر إضافة] → [نموذج البيانات] 
→ [حفظ] → [قائمة الطلاب] → [بحث/ترتيب]
```

### 5.2 تدفق إدخال درجات
```
[لوحة التحكم] → [إدخال الدرجات] → [اختيار طالب] → [اختيار فصل] 
→ [اختيار شهر] → [إدخال 4 درجات] → [تحديث تلقائي للمجموع] 
→ [حفظ] → [زر التالي/السابق]
```

### 5.3 تدفق الاستيراد (CSV/XLSX)
```
[لوحة التحكم] → [استيراد] → [اختيار ملف عبر SAF] → [معاينة] 
→ [اكتشاف/ربط الأعمدة] → [تقرير الأخطاء] → [تنفيذ في معاملة واحدة] 
→ [تأكيد] → [قائمة محدثة]
```

### 5.4 تدفق التصدير (PDF/Excel)
```
[لوحة التحكم] → [تصدير] → [اختيار الصيغة] → [اختيار النطاق] 
→ [تخصيص التقرير] → [حفظ/مشاركة]
```

## 7. الأمن والصلاحيات (Security & Permissions)

| الصلاحية | الغرض | ملاحظة |
|----------|-------|---------|
| `READ_EXTERNAL_STORAGE` / SAF | فتح ملفات CSV/XLSX | عبر Android Storage Access Framework |
| `WRITE_EXTERNAL_STORAGE` / SAF | حفظ ملفات التصدير والنسخ الاحتياطي | |
| `INTERNET` | **ممنوع** (لا يُستخدم) | التطبيق مستقل بالكامل |

**ملاحظات أمنية:**
- جميع البيانات مشفرة محلياً (SQLite مع TDE عند الإمكان).
- التحقق من سلامة ملفات النسخ الاحتياطي قبل الاستعادة.
- رسالة تأكيد قبل حذف أي طالب أو استبدال البيانات.
- لا تُستخدم أي خدمة سحابية أو Firebase أو واجهات API خارجية.

## 8. إمكانية الوصول (Accessibility)

- دعم RTL كامل من الأساس (لا عكس لاحقاً).
- مقاييس تباين تلبي WCAG 2.1 (نسبة تباين 4.5:1 على الأقل).
- دعم قارئ الشاشة (TalkBack) مع تسميات وصفية لكل العنصر.
- أحجام خطوط قابلة للتعديل مع الحفاظ على الترتيب.
- أهداف اللمس ≥ 48dp لجميع الأزرار.
- دعم الوضع الداكن مع تباين مناسب.

## 9. معايير القبول (Acceptance Criteria)

### 9.1 الحسابات
- [ ] المجموع الشهري = الواجبات + الشفهي + المواظبة + التحريري (أقصى 100).
- [ ] معدل الفصل = مجموع 3 أشهر ÷ 3 (أقصى 100).
- [ ] المعدل السنوي = مجموع 6 أشهر ÷ 6 (أقصى 100).
- [ ] النسبة = (المجموع ÷ 600) × 100.
- [ ] النجاح: ≥50% | الرسوب: <50%.
- [ ] التقديرات (ممتاز/جيد جداً/جيد/مقبول/راسب) قابلة للتعديل من الإعدادات.

### 9.2 معالجة البيانات الناقصة
- [ ] الخانة الفارغة ≠ الصفر.
- [ ] لا تُحسب النتيجة النهائية إذا كانت هناك درجات ناقصة.
- [ ] تنبيه واضح عند محاولة اعتماد نتيجة غير مكتملة.
- [ ] معالجة `#REF!`, `#VALUE!`, `N/A` كقيم غير صالحة.
- [ ] لا يحدث انهيار (Crash) بسبب بيانات غير صحيحة.

### 9.3 الأداء
- [ ] استيراد 200+ طالب في أقل من 10 ثوانٍ.
- [ ] استجابة واجهة <200ms عند التعديل.
- [ ] عمل كامل بدون إنترنت (اختبار مع إيقاف الشبكة).

### 9.4 الاختبارات
- [ ] Unit Tests لمحرك الحسابات (تغطية ≥80%).
- [ ] اختبارات Room للعمليات الأساسية.
- [ ] اختبارات استيراد/تصدير.
- [ ] اختبار Build ناجح بدون أخطاء Gradle/Kotlin.

### 9.5 المخرجات النهائية
- [ ] مشروع Android Studio كامل قابل للفتح والتطوير.
- [ ] ملف APK قابل للتثبيت.
- [ ] وثائق تشغيل وبناء.

## 11. الافتراضات (Assumptions)

1. **نظام التقديرات الافتراضي:** ممتاز (≥90%)، جيد جداً (80-89%)، جيد (70-79%)، مقبول (50-69%)، راسب (<50%) — قابل للتعديل من الإعدادات.
2. **التصنيف الفارغ:** الطالب غير المكتمل لا يُصنَّف في أي تقدير ولا يُدرج في الترتيب النهائي.
3. **التساوي في الترتيب:** الطلاب المتساون في الدرجة يتشاركون المركز نفسه، ويتقدم التالي حسب الترتيب الطبيعي.
4. **تنسيق الأرقام:** يدعم الأعداد الصحيحة والكسور العشرية (نقطة عشرية كما في الإدخال).
5. **النسخ الاحتياطي:** ملف واحد مشفر يحتوي على قاعدة البيانات كاملة + الإعدادات.

## 15. ملاحظات تنفيذية للمطور

1. **لا تُختصر** إلى نموذج أولي — كل زر يجب أن يكون له وظيفة فعلية.
2. **لا تستخدم** بيانات وهمية — قاعدة بيانات حقيقية من البداية.
3. **لا تفتقد** بيانات الطلاب عند التحديث — migrations آمنة.
4. **لا تحسب** النتائج قبل اكتمال الرصد.
5. **احفظ** التصميم العربي الاحترافي وسهل الاستخدام.
6. **اجعل** التطبيق سريعاً حتى مع 200+ طالب.
7. **لا تعدّل** توزيع الدرجات أو أسماء الأشهر دون إذن.
8. **لا تُغيّر** متطلب أساسي دون توضيح السبب.
