# MyApp

مشروع أندرويد مولَّد بواسطة وكيل «توليد تطبيقات الأندرويد» — Alborihi AI.

- الحزمة: `com.alborihi.myapp`
- minSdk 24 / targetSdk 34
- الواجهة: Jetpack Compose + Material 3

افتح المجلد في Android Studio، أو راجع `SIGNING.md` للبناء والتوقيع. يتضمن `.github/workflows/android.yml` بناءً تلقائياً على GitHub.
